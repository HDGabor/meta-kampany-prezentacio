# Meta hirdetési stratégia prezentáció

Egyfájlos, önálló HTML prezentáció (vanilla JS) Meta hirdetési stratégiáról adománygyűjtő kampányokhoz.

- Élő: https://meta-kampany-prezentacio.vercel.app
- Admin mód: minden szöveg szerkeszthető (contenteditable), localStorage-ban perzisztál
- Vetítő mód: fullscreen, nyíl/szóköz navigáció
